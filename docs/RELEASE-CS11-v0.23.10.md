# 基于领克CS11车机版本优化的DiPaly v0.23.10

> 参考原作者DiPlay项目优化

这是面向 **领克 CS11 / OneOS 车机**、**Android 4.4.3 / API 19** 的实验性无线 CarPlay 适配版本。本版本重点解决车机音频控制、无线连接后的蓝牙抢占、领克方向盘按键与 ECARX DIM 仪表导航适配，并保留此前针对老平台的连接与解码兼容优化。

## v0.23.10 重点更新

### 独立音乐 / 导航音量
- 首页提供 **音乐音量** 与 **导航音量** 两个独立滑杆。
- 导航 PCM 播报发生时，音乐自动降低到当前设定音量的 **28%**。
- 导航提示结束约 **0.9 秒** 后，音乐自动恢复到用户原先选择的音量。
- 静音 RTP 不会持续触发音乐压低，避免导航结束后音乐长期处于低音量。

### 无线 CarPlay 音频
- Android 4.4 端仅对无线输出声明 **PCM / AAC** 解码能力。
- Opus 仅用于协商后的麦克风输入，不作为 Android 4.4 车机输出解码格式。
- 继续采用软件音频焦点与软件播放路径，降低车机原生蓝牙音频抢占带来的影响。
- 通话场景临时进入 communication mode，结束后恢复原音频状态。

### Wi-Fi 交接后自动断开手机蓝牙
- 在无线 CarPlay 的 Wi-Fi 隧道完成认证交接后，尝试通过 **ECARX 原厂蓝牙服务**断开当前已选 iPhone。
- 同时保留 Android A2DP / HFP 兼容回退。
- **不会删除配对记录，也不会关闭车机蓝牙总开关**，目的是避免声音继续由蓝牙链路输出。
- 软件音频与蓝牙断开仍需要不同 CS11 固件进行实车验证。

### 领克 CS11 / OneOS 方向盘控制
- 支持语音键 / Siri、上一曲、下一曲、播放 / 暂停。
- 同时保留 Android MEDIA_BUTTON 与 Skypine 语音按键回退路径。
- 可在应用中启停后台按键监听。
- 提供 15 秒数字按键事件诊断，便于不同固件核对物理按键映射。

### ECARX DIM 仪表导航
- 保留领克 DIM 导航运行时适配。
- 已整理 101 车辆标记及 102–120 转向类型族。
- 实测映射样例：右转 **103**、右前方 **105**、左侧掉头 **108**。
- 路线开始与到达 / 停车标记不主动显示。
- 保留完整 maneuver 顺序、道路文字与驾驶侧信息；缺失字段不会简单跳过。
- 支持 60 秒路线采集、只读 OEM DIM 证据导出，以及行驶路线中的按钮式校准。
- 仪表实际图标表现仍取决于车辆固件，需以实车显示为准。

## 显示与性能参数

- 最低系统：**Android 4.4.3 / API 19**
- 默认 CarPlay 请求：**1280 × 650 / 30 fps**
- 可选分辨率：**1024 × 520、768 × 390、512 × 260、1536 × 780**
- 可选刷新率：**30 fps / 60 fps**
- H.264：优先使用厂商 AVC 解码器，失败时回退 Google 软件路径
- 视频输入：8 帧有界队列，并跳过过期解码画面
- 网络：高性能 Wi-Fi Lock；AirPlay control / event TCP keepalive
- 自动恢复：有界自恢复后按 **1.5 / 3 / 5 / 8 / 12 秒**重试
- 麦克风：协商后的通话 / Siri 默认启用 PCM 上行，可自动或手动选择录音源
- 界面：启动显示居中白色菜单；首帧后自动收起；顶部下拉可重新打开；无旧版右下角悬浮按钮
- 默认支持记忆已配对 iPhone 自动连接，并可在设置中调整

## 当前已知限制

- 这是针对领克 CS11 / OneOS 与 i.MX6 老车机环境的实验性适配，不保证其它车型、其它 OneOS 固件或未来 iOS 版本完全兼容。
- 已有一台 i.MX6 固件验证了无线画面、全屏 H.264、基础触摸、记忆手机连接、导航同步和 Siri；**软件音乐 / 导航音频输出、ECARX 蓝牙自动断开仍属于实车继续验证项**。
- 车辆 GPS 可通过 Android LocationManager 读取；iPhone 是否稳定采用车载 GPS 仍未完全验证。
- 尚未完整实现或验证：USB/NCM、Wi-Fi Direct、比亚迪专用 HUD 协议、电池 / 档位 / 轮速上报、HEVC / Opus 输出、完整电话双向音频、iPhone persistent activities。

## 源码状态

仓库中的 `android-4.4-cs11` 分支目前是较早的 CS11 适配源码，**不应被视为 v0.23.10 最终 APK 的精确对应源码**。本次 v0.23.10 发布以经过 SHA-256 校验的最终 APK 为准；在对应最终源码同步完成前，请勿将旧分支构建结果标注为 v0.23.10。
